# HabitGrid

A personal habit tracker inspired by the contribution-style calendars used by platforms like LeetCode and GitHub.

## Features

- Add habits
- Remove habits
- Edit habits
- Choose a different color for each habit
- Mark habits as completed or not completed
- Monthly habit activity tracking
- Previous / next month navigation
- Today's habit progress
- Local data storage using browser localStorage

## Tech Stack

- HTML
- CSS
- JavaScript
- LocalStorage

## Purpose

This is a personal project built to track daily habits in a simple visual way.
